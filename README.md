# Student Management System (Java)

A console-based Java application designed to perform complete CRUD (Create, Read, Update, Delete) operations on student records with file-based data persistence.

## 🚀 Features
- **Add Student:** Insert student details (Roll No, Name, Marks).
- **Display All Students:** View the complete list of registered students.
- **Search Student:** Find specific student records using Roll Number.
- **Update Student:** Edit existing student details seamlessly.
- **Delete Student:** Remove student records by Roll Number.
- **Data Persistence:** Automatically saves records to a binary file (`students.dat`) using Java Object Serialization, keeping data intact even after closing the program.

## 🛠️ Tech Stack & Concepts Used
- **Language:** Java (JDK 8+)
- **Concepts:** Object-Oriented Programming (OOP), Java Collections Framework (`ArrayList`), File Handling (`ObjectOutputStream` & `ObjectInputStream`), Exception Handling, Serialization (`Serializable` interface).
